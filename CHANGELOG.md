# Changelog

Notable changes to the index. This file is generated from `data/updates.yaml`; the same notes are on the website (https://zhenxianli.github.io/psychoacoustic-metrics-index/updates.html) and in its Atom feed.

## 2026-10-06: First public version

The index starts with the projects, methods and standard editions listed on the website. Every
implementation is tied to the edition or model paper it follows, with links to the documentation the
facts were taken from.

Worth knowing as of today:

- ECMA-418-2 is at its 4th edition (June 2025), which added fluctuation strength. Implementations of
  earlier editions are still in use, so check which edition a tool follows before comparing results.
- SQAT's main branch carries unreleased changes to Aures tonality and Daniel & Weber roughness
  (September 2026) that change results compared with SQAT v1.3.
- All three parts of ISO 532 are being revised; committee drafts have existed since November 2024.
- DIN 38455:2024 is the first German standard for roughness. No open implementation is known.
- MetaSona (C library with a Python interface, first released in September 2026) is a new entry.
